ثانياً — التدفق الكامل خطوة بخطوة

🔵 المرحلة 1 — إضافة متعلم جديد
الحقول:
├── الاسم الكامل
├── تاريخ الميلاد
├── المركز أو البرنامج
└── أداة التقييم المستخدمة
    (قائمة منسدلة أو إضافة حرة)

المخرج:
← ملف متعلم جديد في النظام
← الحالة: assessment

🔵 المرحلة 2 — إدخال التقييم
الخطوة أ — نسب المجالات:
TTAP → 6 مجالات تلقائية (VS,VB,IF,LS,FC,IB)
أداة أخرى → إضافة مجالات يدوياً
لكل مجال: نجاح% + ناشئة% + عدم نجاح% = 100%

الخطوة ب — تصنيف البنود (اختياري):
لكل بند → 7 خيارات:
لم يُصنَّف | لم ينجح |
ناشئة×1 | ناشئة×2 | ناشئة×3 |
نجاح×1 | نجاح×2 | نجاح×3

طبقة صامتة 1:
├── ربط البنود بـ 12 مفهوم انتقالي
├── تقييم الأداة بمعايير DCDT
│   (هل تستوفي شروط أداة الانتقال؟)
├── تحديد المفاهيم المغطاة والفجوات
└── بناء بروفايل أولي صامت

المخرج للمختص:
← توصية نصية بسيطة:
  "الأداة غطّت مجالات: ...
   لكن تحتاج مزيداً من المؤشرات في: ...
   يُقترح الاطلاع على المكتبة أو المتابعة"

🔵 المرحلة 3 — المكتبة (اختيارية)
أدوات تكميلية مصنفة حسب المجال
المختص يختار ويدخل النتائج
← نفس آلية التصنيف الثلاثي

طبقة صامتة:
← تُضاف للبروفايل الصامت
← تحديث تغطية المفاهيم

مؤشر تنبيه متكرر:
"الأدوات التكميلية تُثري البروفايل
 ويمكن المتابعة بدونها في أي وقت"

🔵 المرحلة 4 — صوت الأسرة
5 محطات حياتية (المختص مع الأسرة):
🌅 الاستيقاظ وبداية اليوم
🍽️ الغداء والمائدة
🎒 الذهاب للمركز
🧹 طاولة الطعام وتنظيفها
👨‍👩‍👧 التجمع العائلي

لكل محطة:
├── أسئلة سلوكية ملموسة (4 خيارات)
├── chips دعم اختيارية
└── السؤال الوظيفي (AEPS-3):
    "ما المهارة التي ستحدث فرقاً؟"
    🤝 مشاركة واستمتاع
    🌟 استقلالية
    😌 روتين أسهل
    💛 الأهم لنا الآن

المحطة 5 تنتهي بـ:
"تخيّلوا [اسم] بعد 5 سنوات..."
← family_vision

طبقة صامتة 2:
├── مستوى الأداء في البيئة المنزلية
├── المدعمات والمحفزات
├── أولويات الأسرة (AEPS-3 matching)
├── مواقف النجاح
└── رؤية الأسرة

جميع الحقول النصية اختيارية —
لا توقف التقدم

🔵 المرحلة 5 — صوت المتعلم
5 أسئلة بصرية بالإيموجي
(المختص جالس مع المتعلم)

س1: ماذا تحب في وقت فراغك؟
س2: ما الذي تجيده وتفخر به؟
س3: ماذا تريد أن تفعل في المستقبل؟
س4: ما الذي يسعدك في يومك؟
س5: ما الذي تجد صعوبة فيه؟ (اختياري)

طبقة صامتة 3:
├── الاهتمامات والتفضيلات
├── الميول المهنية
└── رؤية المتعلم لمستقبله

← نهاية مرحلة جمع المعلومات

🔵 المرحلة 6 — التقرير الشامل
يجمع جميع المصادر الثلاثة:

القسم 1 — المستوى الحالي في المفاهيم:
لكل مفهوم من الـ 12:
├── المستوى الحالي (من الطبقة الصامتة)
├── نقاط القوة (بنود نجاح×3 و×2)
├── مناطق التطوير (بنود ناشئة)
└── مصدر المعلومة (أداة/أسرة/متعلم)

القسم 2 — صوت المتعلم:
├── اهتماماته وتفضيلاته
└── رؤيته لمستقبله

القسم 3 — صوت الأسرة:
├── ما يجيده في البيت
├── المدعمات المتاحة
├── أولوياتهم (AEPS-3 aligned)
└── رؤيتهم لمستقبله

القسم 4 — متنبئات الانتقال:
ما الذي يدعم نجاحه بناءً على الأبحاث
(NTACT:C Predictors)

القسم 5 — توصيات للاستهداف:
"يمكن استهداف المستويات التالية في:
 مفهوم كذا / مفهوم كذا"
← ليست أهدافاً جاهزة
← مقترحات مجالات للمختص

🔵 المرحلة 7 — إدخال الخطة التربوية
تُعرض مجالات أداة التقييم:
(VS / VB / IF / LS / FC / IB)

المختص لكل مجال:
├── يختار المجال
└── يكتب الأهداف بحرية كاملة
    (حتى 4 أهداف/مجال = 24 هدفاً)

طبقة صامتة 4 — المعايرة:
لكل هدف مُدرج:
├── ربطه بمفهوم انتقالي
├── تحديد المستوى الحالي والمستهدف
│   (من المصفوفة السداسية للمفاهيم)
├── اقتراح 3-4 أنشطة وظيفية
└── اقتراح سياق تدريبي مرتبط
    بالمحطات المنزلية الخمس

🔵 المرحلة 8 — الخطة النهائية
جدول لكل هدف:

┌─────────────────────────────────────────────┐
│ الهدف          ← المختص يكتبه              │
│ المفهوم        ← من المعايرة (صامت)        │
│ الوسيلة        ← المختص يختارها            │
│ تاريخ البداية  ← المختص يحدده             │
│ تاريخ النهاية  ← المختص يحدده             │
├─────────────────────────────────────────────┤
│ الأنشطة المقترحة (قائمة — يختار منها ✓)   │
│ • نشاط 1                                   │
│ • نشاط 2                                   │
│ • نشاط 3                                   │
├─────────────────────────────────────────────┤
│ السياق التدريبي (نقاط — يختار منها ✓)      │
│ • في محطة الغداء: ...                      │
│ • في محطة الذهاب للمركز: ...               │
│ • في التجمع العائلي: ...                   │
└─────────────────────────────────────────────┘

المختص يضع ✓ على ما يختاره
← تكتمل الخطة في صورتها النهائية
← قابلة للتصدير PDF

ثالثاً — بنية البيانات النهائية (xPress IEP متوافق)
typescriptinterface HimamIEP {
  // معلومات المتعلم
  student: {
    id: string
    name: string
    birthDate: string
    center: string
    createdAt: string
    status: StudentStatus
  }

  // التقييم
  assessment: {
    tool: string
    domains: Domain[]
    itemClassifications: Record<string, ItemRating>
    completedAt: string
  }

  // البروفايل الصامت
  profile: {
    conceptLevels: Record<ConceptName, number>
    strengthItems: ProfileItem[]
    emergingItems: ProfileItem[]
    challengeItems: ProfileItem[]
    computedAt: string
  }

  // صوت الأسرة
  familyStations: {
    stations: Record<number, StationData>
    familyVision: string
    supports: string[]
    priorities: FamilyPriority[]
    successStories: string[]
    conceptContributions: Record<ConceptName, number>
  }

  // صوت المتعلم
  studentVoice: {
    interests: string[]
    strengths: string[]
    futureVision: string
    happinessSources: string[]
    challenges: string[]
  }

  // الخطة التربوية
  iep: {
    goals: IEPGoal[]
    completedAt: string
  }

  // الخطة النهائية
  finalPlan: FinalPlanRow[]
}

interface IEPGoal {
  id: string
  domain: string        // VS | VB | IF | LS | FC | IB
  text: string          // المختص يكتبه
  tool: string          // المختص يختارها
  startDate: string
  endDate: string
  // من المعايرة (صامت)
  concept: ConceptName
  conceptLevel: number
  suggestedActivities: Activity[]
  trainingContext: TrainingContext[]
  // المختص يختار
  selectedActivities: string[]
  selectedContexts: string[]
}

interface FinalPlanRow {
  goalId: string
  goalText: string
  concept: ConceptName
  conceptLevel: number
  tool: string
  startDate: string
  endDate: string
  activities: string[]    // المختارة فقط
  contexts: string[]      // المختارة فقط
}
