# خطة تنفيذ دورة البناء 07 - شاشة إعداد الهدف ومرتكز الأداء

## قرار المنتج المرجعي

اسم الدورة: `BUILD_CYCLE_07`

النطاق الملزم: `GOAL_AUTHORING_BASELINE_SOURCE_AND_COGNITIVE_LOAD`

تبدأ شاشة إعداد الهدف بقرار المختص بين مسارين:

1. منشئ الهدف التفاعلي.
2. إدراج هدف مباشرة.

بعد اختيار المسار لا ينتقل الهدف إلى مسودة قابلة للمراجعة إلا بوجود:

- مجال أداة التقييم.
- باعث الهدف.
- مرجعية الخط القاعدي.
- مرتكز أداء مفسر أو بند أداة تقييم مختار.

## قاعدة مرجعية الخط القاعدي

`FORMAL_THEN_INFORMAL_BASELINE_PRIORITY`

مرتكز الأداء لا يساوي باعث الهدف. باعث الهدف قد يأتي من صوت الأسرة أو صوت المتعلم أو ملاحظة الفريق أو متطلبات الانتقال، أما مرتكز الأداء فيجب أن يستند إلى أداء حالي موثق بالترتيب التالي:

1. أداة تقييم رسمية مفسرة كأولوية أولى.
2. أداة تقييم غير رسمية أو قائمة مسح واضحة.
3. ملف أو نموذج مرفوع ومراجع.

عند اختيار أداة تقييم رسمية تعرض الشاشة بنود الأداة داخل مجال التقييم ليختار المختص البند الذي يمثل خط الأداء القاعدي. وعند اختيار مصدر غير رسمي أو ملف مراجع يطلب النظام وصفاً منظماً يتضمن اسم الأداة أو الملف والبند أو النتيجة أو التفسير.

## قاعدة خفض العبء المعرفي

`DETAILS_ON_DEMAND`

تظهر للمختص مستخلصات رئيسية فقط عن معالجة المعلومات والبروفايل ومصادر الملفات داخل شاشة المجال. التفاصيل التشغيلية لا تعرض افتراضياً، وتشمل:

- مصادر الملفات المراجعة.
- معالجة المعلومات.
- البروفايل المتكامل.

تظهر هذه التفاصيل فقط عند طلبها من المختص. شاشة الدعم المعرفي تبقى قابلة للاستدعاء ولا تزاحم مسار الأسئلة.

## خارج نطاق هذه الدورة

- إعادة تصميم جميع الشاشات بصرياً.
- بناء رخص أو تصحيح سيكومتري كامل للأدوات المقننة.
- تحويل كل مصادر المعلومات إلى مكتبات بنود كاملة.

هذه البنود تبقى مؤجلة ومصنفة ولا تمنع إغلاق هذه الدورة إذا تحقق تعديل شاشة الهدف وفاحصها الآلي.

## بوابة الجاهزية

تعد الدورة جاهزة إذا تحقق الآتي:

- وجود قرار مسار إنشاء الهدف في بداية الشاشة.
- وجود مرجعية خط قاعدي مستقلة عن باعث الهدف.
- إلزام الأداة الرسمية باختيار بند تقييم.
- إلزام الأداة غير الرسمية أو الملف المراجع بوصف خط قاعدي مفسر.
- إخفاء تفاصيل معالجة المعلومات والبروفايل والملفات خلف أزرار عرض.
- تشغيل `npm run verify:build-cycle-07`.
- تشغيل `npm run typecheck`.
- تشغيل `npm run lint`.
- تشغيل `npm run build`.
