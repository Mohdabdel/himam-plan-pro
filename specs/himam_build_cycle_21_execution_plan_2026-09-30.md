# خطة تنفيذ دورة البناء 21 - البدء الذكي في شاشة توليد الأهداف

## قرار المنتج المرجعي

اسم الدورة: `BUILD_CYCLE_21`

النطاق الملزم: `GOAL_AI_SMART_START`

تعالج هذه الدورة فجوة تجربة المستخدم في شاشة توليد الأهداف: وجود طبقة AI لا يكفي إذا كان المختص مضطراً لاختيار نمط العمل والمجال قبل أن يرى دعماً فعلياً. لذلك تضيف الدورة مساحة بدء ذكي تعرض أقوى المقترحات قبل اختيار المسار.

## قاعدة التشغيل

- تعرض شاشة الأهداف حتى 3 مقترحات AI قبل اختيار نمط العمل.
- يستطيع المختص بدء التحرير من المقترح دون المرور بكل الأسئلة.
- يستطيع المختص إضافة المقترح كمسودة فقط عندما لا يحتاج دليلاً.
- تبقى حدود طبقة AI كما هي: لا اعتماد، لا خط قاعدي مولد، لا قرار آلي.

## سيناريو المستخدم

يفتح المختص شاشة الأهداف، فيرى مساحة `بدء ذكي من طبقة AI`. يختار مقترحاً، ثم:

- يبدأ التحرير، فتُملأ الحقول الأساسية تلقائياً.
- أو يضيف المقترح كمسودة هدف إذا كان مرتبطاً بدليل كاف.

## تصميم الواجهة

تضاف مساحة أعلى اختيارات نمط العمل:

- عنوان: `بدء ذكي من طبقة AI`.
- ملخص عدد المقترحات.
- بطاقات مقترحات مختصرة.
- زر `بدء التحرير`.
- زر `إضافة كمسودة`.

## بوابة الجاهزية

تعد الدورة جاهزة إذا تحقق الآتي:

- تشغيل `npm run verify:build-cycle-21`.
- تشغيل `npm run typecheck`.
- تشغيل `npm run lint`.
- تشغيل `npm run build`.
