# خطة تنفيذ دورة البناء 15 - جدول خدمات الدعم المقررة

## قرار المنتج المرجعي

اسم الدورة: `BUILD_CYCLE_15`

النطاق الملزم: `STRUCTURED_SUPPORT_SERVICES_TABLE`

تحول هذه الدورة خدمات الدعم من إدخال نصي حر فقط إلى إدخال مهني منظم ينتج جدولاً واضحاً داخل شاشة الأهداف.

## خدمات الدعم

- تتكون كل خدمة من:
  - نوع الخدمة.
  - اسم الخدمة.
  - الأهداف المرتبطة.
- بعد إضافة الخدمة تظهر في جدول بثلاثة أعمدة فقط: نوع الخدمة، اسم الخدمة، الأهداف المرتبطة.
- يسمح الجدول بحذف خدمة مدخلة قبل الحفظ.
- يدعم التحميل البيانات القديمة التي كانت محفوظة كنصوص.

## التقرير

- يقرأ التقرير الخدمات القديمة كنصوص والخدمات الجديدة كصفوف منظمة.
- لا ينكسر التقرير عند وجود أي من الشكلين.

## بوابة الجاهزية

تعد الدورة جاهزة إذا تحقق الآتي:

- تشغيل `npm run verify:build-cycle-15`.
- تشغيل `npm run typecheck`.
- تشغيل `npm run lint`.
- تشغيل `npm run build`.
