# خطة تنفيذ دورة البناء 20 - حفظ أثر طبقة AI في مسار الهدف والخطة

## قرار المنتج المرجعي

اسم الدورة: `BUILD_CYCLE_20`

النطاق الملزم: `AI_SUGGESTION_PROVENANCE_TO_PLAN`

تعالج هذه الدورة فجوة تتبع مهنية: عندما يضيف المختص هدفاً من مقترحات طبقة AI، يجب ألا ينتقل الهدف كأنه مكتوب يدوياً بالكامل دون وسم. يجب حفظ أثر طبقة AI كمعلومة مراجعة فقط داخل الهدف ثم عرضه عند مراجعة الخطة.

## قاعدة التشغيل

- وسم AI لا يعني اعتماد الهدف.
- وسم AI لا يغير موانع الجودة.
- وسم AI لا يضيف دليلاً أو خطاً قاعدياً.
- وسم AI ينتقل مع الهدف إلى شاشة الخطة كقرينة مصدر صياغة/اقتراح فقط.

## تصميم البيانات

أضيف حقل اختياري على هدف الخطة التربوية:

`aiSuggestion`

ويحتوي:

- اسم طبقة AI.
- معرف المقترح.
- معرف فرصة الهدف.
- نوع المقترح.
- حالة الجاهزية.
- سبب الترشيح.
- حدود الطبقة.
- وقت الإضافة.

## تصميم الواجهة

- في شاشة الأهداف، يظهر وسم طبقة AI داخل تفاصيل الهدف عند التوسيع.
- في شاشة الخطة، يظهر وسم طبقة AI ضمن تفاصيل الهدف المعتمد عند الطلب.

## بوابة الجاهزية

تعد الدورة جاهزة إذا تحقق الآتي:

- تشغيل `npm run verify:build-cycle-20`.
- تشغيل `npm run typecheck`.
- تشغيل `npm run lint`.
- تشغيل `npm run build`.
