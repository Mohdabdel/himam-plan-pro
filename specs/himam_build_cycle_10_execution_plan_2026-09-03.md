# خطة تنفيذ دورة البناء 10 - تحسين عرض الشاشات حتى توليد الأهداف

## قرار المنتج المرجعي

اسم الدورة: `BUILD_CYCLE_10`

النطاق الملزم: `SCREEN_SIMPLIFICATION_TO_GOAL_GENERATION_PAUSE`

تنتهي هذه الدورة عند شاشة توليد الأهداف. لا تعيد الدورة بناء منطق منشئ الهدف التفاعلي العميق؛ لأن هذا الجزء يحتاج مناقشة لاحقة حول علاقة الهدف العام، الهدف السنوي، الأثر الوظيفي، واستمرارية المسار عبر السنوات.

## شاشة التقييم الرسمي

- حذف اسم المقيم أو المختص وتاريخ التطبيق من واجهة الإدخال، لأنهما يفترضان داخل ملف نتائج التقييم.
- إبقاء عبارة رفع ملف نتائج التقييم النهائية ومراجعة مسودة القراءة قبل تحويلها إلى مرجعية مهنية.
- إظهار تنويه عمر 14 فأكثر حول محدودية بعض أدوات التقييم الرسمية في تغطية مفاهيم الانتقال مثل تقرير المصير والوعي الذاتي ومهارات الحياة.
- تبسيط صندوق الرفع إلى رابط التحميل والصيغ المقبولة.
- تغيير عنوان مكتبة الأدوات إلى معالج نتائج أدوات التقييم الرسمية.
- عرض الأدوات الرسمية في قائمة منسدلة بأسمائها فقط.
- إخفاء مسودة قراءة الملف القابلة للتصحيح خلف عنوان يفتح عند الطلب.
- إضافة خيار رفع تقييمات إضافية رسمية أو غير رسمية كمدخل لاحق للمعالجة.

## شاشة صوت الأسرة

- أداة بطاقات رؤية الأسرة المصورة تعرض كتطبيق ذاتي موجه للأسرة أثناء الجلسة.
- تعرض بطاقات مواقف حوارية واختيارات مختصرة قبل تسجيل الإجابات.

## شاشة كفاية المعلومات

- إظهار تنويه للتقييم الرسمي عند انطباق إطار التخطيط للانتقال.
- إبقاء مؤشرات مبسطة في الواجهة.
- إخفاء تفاصيل معالجة المعلومات والبروفايل وبطاقات الأداء خلف عنوان المزيد من المعلومات.
- حذف مدخل شاشة الدعم المعرفي التالية.

## شاشة إعداد الخطة التربوية

- تبدأ بعنوان إعداد الخطة التربوية الفردية.
- تعرض قائمة منسدلة لمكونات الخطة: البيانات الأساسية، مستوى الأداء الحالي، رؤية المختص، تصميم الأهداف.
- تشير القائمة إلى اكتمال البنود بعلامة تحقق نصية.
- مستوى الأداء الحالي يعرض جدولاً: المجال، نقاط القوة، نقاط الاحتياج.
- تعبأ مسودة الجدول من التقييم الرسمي وبقية مصادر جمع المعلومات عند توفرها، مع إتاحة تعديل المختص.

## شاشة توليد الأهداف

- تعديل عنوان الشاشة إلى محرك توليد الأهداف التفاعلي.
- إضافة تعريف مختصر للمحرك.
- توضيح خيار منشىء الهدف التفاعلي وخيار إدخال مباشر للأهداف مع دعم معرفي مواز عند الطلب.
- التوقف بعد هذه النقطة لمناقشة منطق منشئ الهدف التفاعلي قبل تعميقه.

## شاشة مراجعة الخطة النهائية

- تخفيف الحمل المعرفي بعرض إشارات السياق، مراجعة جودة الخطة، وتفاصيل كل هدف معتمد عند الطلب فقط.
- لا يحذف الإخفاء أي نتيجة مراجعة أو توصية؛ بل يغير زمن ظهورها للمختص أثناء القراءة.

## بوابة الجاهزية

تعد الدورة جاهزة إذا تحقق الآتي:

- تشغيل `npm run verify:build-cycle-10`.
- تشغيل `npm run typecheck`.
- تشغيل `npm run lint`.
- تشغيل `npm run build`.
