# خطة تنفيذ دورة البناء 11 - ضبط معالج التقييم الرسمي ومسودة مستوى الأداء

## قرار المنتج المرجعي

اسم الدورة: `BUILD_CYCLE_11`

النطاق الملزم: `OFFICIAL_ASSESSMENT_PROCESSOR_AND_CURRENT_LEVEL_DRAFT`

تعالج هذه الدورة ملاحظتين تشغيليتين بعد تجربة دورة البناء 10: موضع اختيار أداة التقييم الرسمية، وطريقة عرض مسودة مستوى الأداء الحالي.

## شاشة التقييم الرسمي

- يكون عنوان الاختيار: أداة التقييم الرسمية المطبقة مع المتعلم.
- يحل معالج نتائج التقييم الرسمية محل اختيار الأداة المنفصل، بحيث يتم اختيار الأداة من القائمة المنسدلة نفسها.
- يظهر تعريف المعالج كتلميح مخفي عبر علامة معلومات بجانب العنوان.
- تبقى مجالات قراءة نتائج الأداة مخفية، ولا تعرض إلا عند طلبها من عنوان قابل للاستدعاء.
- لا يتم إدخال درجات أو تقديرات يدوية للتقييم الرسمي داخل الشاشة.

## شاشة مستوى الأداء الحالي

- يبدأ المكون بجدول نقاط القوة ونقاط الاحتياج المصنفة وفق مجالات أداة التقييم الرسمية.
- تعرض المنصة المسودة المقترحة باعتبارها ناتجة عن معالجة إجمالي مصادر المعلومات.
- يمكن للمختص تعديل المسودة أو الإضافة عليها أو استبعادها وبناء المحتوى ذاتياً.
- تخفى تفاصيل المعالجة السابقة خلف خيار استدعاء الملف التفصيلي لمعالجة مصادر المعلومات.

## بوابة الجاهزية

تعد الدورة جاهزة إذا تحقق الآتي:

- تشغيل `npm run verify:build-cycle-11`.
- تشغيل `npm run typecheck`.
- تشغيل `npm run lint`.
- تشغيل `npm run build`.
