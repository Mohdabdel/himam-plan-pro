# Himam Build Cycle 04 Execution Plan

تاريخ الإصدار: 2026-08-29  
الحالة: دورة برمجة لمحرك مكونات البروفايل  
النطاق: بناء محرك معالجة لجميع إدخالات المعلومات السابقة يفرزها في مكونات بروفايل قابلة للاستدعاء أثناء إعداد وتحسين الهدف.

## 1. قرار منتج مرجعي

الأولوية ليست توسيع الأدوات والنماذج، بل تفسير نتائجها ومعالجة معلوماتها لبناء بروفايل موجه ومفسر لمستوى المتعلم الحالي. لذلك يجب أن يبدأ المحرك من مكونات أساسية للبروفايل، ثم يربط كل مدخل معلومات بالمكون والعنصر الداخلي ودرجة أثره على صحة الهدف أو جودة الهدف.

## 2. سيناريو مستخدم محدد

كمختص، بعد إدخال صوت الأسرة أو صوت المتعلم أو رفع نتائج تقييم رسمي أو إضافة مصدر معلومات، أفتح كفاية المعلومات أو إعداد الهدف فأرى:

- ما المكونات التي تغطت من البروفايل.
- ما العناصر المهمة داخل كل مكون مثل رؤية الأسرة، أولويات الأسرة، تفضيلات المتعلم، الدعم، المخاطر، ونتائج التقييم.
- هل العنصر يؤثر على صحة الهدف أم يحسن جودة صياغته.
- ما الفجوات التي يجب استكمالها قبل اعتماد هدف قوي.
- تلميحات استدعاء تساعدني على استخدام المعلومة في صياغة الهدف.

## 3. متطلبات مجال وصلاحيات

- لا يعتمد المحرك هدفاً تلقائياً.
- كل عنصر يبقى منسوباً إلى مصدره الأصلي.
- مكونات نتائج التقييم الرسمي لا تنتج من إدخال درجات يدوي، بل من ملف نتائج مرفوع ومراجع.
- مكونات صوت الأسرة وصوت المتعلم يمكن أن تنتج من تطبيق أداة داخل المنصة أو من نموذج مرفوع ومراجع.
- العناصر الحرجة تؤثر على صحة الهدف أو قوة مراجعته، والعناصر المهمة تحسن الملاءمة والتخصيص والجودة.

## 4. تصميم بيانات مع migration قابلة للمراجعة

لا توجد migration في هذه الدورة. أضيفت طبقة مشتقة داخل نموذج المعالجة:

```text
ProcessedProfileInput[]
→ ProfileComponentElement[]
→ ProfileComponentCoverage[]
→ LearnerProfileComponentMatrix
→ LearnerProfileProcessingModel.componentMatrix
```

## 5. API أو service contract

العقود البرمجية:

```text
buildProfileComponentMatrix(processedInputs)
classifyProfileComponentIds(input)
componentElementsForDomain(model, domainCode)
LearnerProfileProcessingModel.componentMatrix
```

## 6. تصميم واجهة

تظهر المصفوفة في:

- شاشة كفاية المعلومات كتغطية مكونات البروفايل والفجوات المؤثرة.
- شاشة إعداد الأهداف كلائحة استدعاء للعناصر ذات الصلة بالمجال المختار.
- لوحة محرك مكونات البروفايل داخل كل مجال هدف.

## 8. مراجعة أمنية للوظائف الحساسة

لا تضيف الدورة معالجة خارجية أو إرسال بيانات إلى AI. المصفوفة تستخدم مدخلات محفوظة محلياً أو مصادر مرفوعة راجعها المختص، وتحتفظ بالإسناد للمصدر.

## 11. demo على سيناريو واقعي

1. تطبيق أداة صوت الأسرة أو صوت المتعلم.
2. رفع نتائج تقييم رسمي قابلة للقراءة.
3. فتح كفاية المعلومات ورؤية مصفوفة مكونات البروفايل.
4. فتح إعداد الأهداف واختيار مصدر البروفايل.
5. رؤية العناصر المرتبطة بالمجال وأثرها على صحة الهدف أو جودة صياغته.
