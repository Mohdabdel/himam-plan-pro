# HIMAM Build Cycle 27 Execution Plan

## Scope

`ASSESSMENT_HUB_SINGLE_VISIBLE_PATH`

## Product Decision

صفحة مصادر جمع المعلومات لا تعرض أكثر من مسار تنقل ظاهر في الوقت نفسه. يظهر للمختص المسار العام الأعلى وزر الانتقال التالي فقط، بينما تبقى مكونات جمع المعلومات الفرعية مخفية وتستدعى عند الحاجة للمراجعة أو العودة لمكون محدد.

## User Scenario

يدخل المختص إلى صفحة مصادر جمع المعلومات بعد اختيار المتعلم. خلال أول 30 ثانية يرى الخطوة العامة الحالية وزر الانتقال إلى أداة التقييم الرسمية، ولا يواجه شرائح أو بطاقات موازية توحي بوجود مسارات متعددة. إذا احتاج مراجعة المكونات، يفتح مساحة "عرض مكونات جمع المعلومات" اختياريا.

## Implementation Requirements

- إبقاء `JourneyStepper` كمسار عام ظاهر.
- إزالة شرائح المسار الفرعي الظاهرة من الصفحة الرئيسية لمصادر جمع المعلومات.
- إبقاء زر `التالي: أداة التقييم الرسمية` كدعوة الإجراء الأساسية.
- إخفاء `PlanComponentsStatus` وبطاقات المكونات خلف زر عرض/إخفاء.
- توضيح أن المكونات الفرعية مساحة مراجعة اختيارية وليست مسارا إضافيا.

## Review Gate

لا تنتقل الدورة التالية قبل نجاح فحص الدورة 27، وفحوصات النوع، والجودة، والبناء، والتحقق من الوثائق الحاكمة.
