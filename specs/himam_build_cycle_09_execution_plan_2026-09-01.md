# خطة تنفيذ دورة البناء 09 - مكون مستوى الأداء الحالي داخل قالب الخطة

## قرار المنتج المرجعي

اسم الدورة: `BUILD_CYCLE_09`

النطاق الملزم: `PLAN_TEMPLATE_CURRENT_PERFORMANCE_COMPONENT`

مستوى الأداء الحالي داخل الخطة مكوّن مستقل عن شاشة الدعم المعرفي وعن البروفايل التشغيلي. يستخدم الدعم المعرفي والبروفايل لتوجيه المختص، أما مكوّن الخطة فيصاغ كنص مهني رسمي قابل للتنقيح والحفظ ضمن نموذج الخطة.

## ترتيب مكونات الخطة

بعد اعتماد الأهداف كوحدات صالحة للإدراج، يبدأ قالب الخطة من:

1. البيانات الأساسية.
2. مستوى الأداء الحالي كمكوّن خطة.
3. رؤية الخطة التربوية الفردية لفريق العمل الصفي.
4. الأهداف المعتمدة للإدراج.
5. الأنشطة والسياقات وخدمات الدعم.
6. مراجعة الخطة كوحدة واعتماد المختص الأعلى.

## قاعدة صياغة مستوى الأداء الحالي

`CURRENT_PERFORMANCE_IS_PLAN_COMPONENT`

تصاغ المسودة الأولية من نتائج أداة التقييم الرسمي كأولوية، وتعرض نقاط القوة ونقاط الاحتياج أو المهارات الناشئة مطابقة لمجالات التقييم. يمكن تدعيم الصياغة بأولويات الأسرة وصوت المتعلم، لكن لا تتحول إلى نص نهائي إلا بعد تنقيح المختص داخل قالب الخطة.

## قاعدة المخرج النهائي

`APPROVED_PLAN_OUTPUT_INCLUDES_CURRENT_PERFORMANCE`

عند حفظ مسودة الخطة، يحفظ النظام مكوّن مستوى الأداء الحالي ورؤية الخطة مع الخطة. وعند عرض التقرير/المخرج النهائي تظهر هذه المكونات ضمن مكونات الخطة، حتى لا يبقى مستوى الأداء الحالي مجرد ملخص شاشة أو دعم معرفي.

## خارج نطاق هذه الدورة

- بناء محرر وثائق كامل لقالب الخطة.
- إعادة ترقيم كل أقسام التقرير بصرياً.
- اعتماد نص مستوى الأداء الحالي آلياً دون مراجعة المختص.

## بوابة الجاهزية

تعد الدورة جاهزة إذا تحقق الآتي:

- شاشة الخطة تعرض البيانات الأساسية.
- شاشة الخطة تعرض مستوى الأداء الحالي كمكوّن خطة قابل للتحرير.
- شاشة الخطة تعرض رؤية الخطة التربوية الفردية لفريق العمل الصفي.
- حفظ الخطة يخزن `currentPerformanceStatement`.
- حفظ الخطة يخزن `planVision`.
- التقرير يقرأ ويعرض مكوّن مستوى الأداء الحالي ورؤية الخطة.
- تشغيل `npm run verify:build-cycle-09`.
- تشغيل `npm run typecheck`.
- تشغيل `npm run lint`.
- تشغيل `npm run build`.
