# خطة تنفيذ دورة البناء 18 - محرك فرص الأهداف ومقترحات الهدف

## قرار المنتج المرجعي

اسم الدورة: `BUILD_CYCLE_18`

النطاق الملزم: `GOAL_OPPORTUNITY_ENGINE_TO_PLAN_HANDOFF`

تعالج هذه الدورة فجوة سهولة شاشة توليد الأهداف دون خفض معايير الجودة. لا يبدأ المختص من كتابة هدف حر فقط، بل يرى مقترحات مضبوطة ناتجة من مستوى الأداء الحالي، بوصلة العمر/الانتقال، رؤية الخطة، ومصادر البروفايل، مع بقاء القرار البشري والتعديل والحفظ كمسودة ضمن صلاحية المختص.

## سيناريو المستخدم المحدد

كمختص، بعد جمع مصادر المعلومات ومراجعة مستوى الأداء الحالي، أفتح شاشة توليد الأهداف فأختار نمط العمل والمجال، ثم تعرض المنصة حتى 3 مقترحات هدف:

- مقترح قريب من مستوى الأداء الحالي.
- مقترح وظيفي/انتقالي أوسع.
- مقترح تمهيدي عند وجود فجوة بين القدرة الحالية والهدف الأوسع.

أستطيع عرض سبب التوليد والأدلة، ثم إضافة المقترح كمسودة هدف. بعد ذلك يخضع الهدف لمسار الجودة الحالي: مسودة قابلة للاستكمال، أو مسودة غير قابلة للرفع عند وجود موانع، أو إقرار المختص ورفعه لمسار الخطة.

## متطلبات المجال والصلاحيات

- المحرك لا يعتمد هدفاً ولا خطة.
- المحرك لا يستخدم صوت الأسرة أو المتعلم كخط قاعدي منفرد.
- كل مقترح يحتاج مرجعية أداء أو يوسم بأنه يحتاج دليل.
- المقترح ينتقل إلى قائمة الأهداف كمسودة فقط.
- رفع الهدف لمسار الخطة يبقى محكوماً بموانع الجودة الحالية وسجل الاعتماد.

## تصميم البيانات

أضيفت طبقة منطقية غير تخزينية:

- `GoalOpportunityCard`: بطاقة فرصة هدف، تحتوي المجال، المهارة، الخط القاعدي، باعث الهدف، رابط الانتقال، رابط المنهج، الجاهزية، والموانع.
- `GoalProposal`: مقترح هدف قابل للإضافة كمسودة، يحتوي نص الهدف، السياق، معيار الأداء، طريقة القياس، مرجعية الدليل، باعث الهدف، ومبرر التوليد.

لا تتطلب هذه الدورة migration لأنها تعمل فوق التخزين المحلي الحالي لمسودات الخطة والأهداف.

## API أو service contract

الواجهة البرمجية الداخلية:

- `buildGoalOpportunityCards(...)`
- `buildGoalProposals(...)`

هذه الدوال تنتج مقترحات مراجعة فقط ولا تحفظ أو تعتمد أي سجل.

## تصميم الواجهة

تضاف داخل شاشة توليد الأهداف مساحة مختصرة باسم:

`مقترحات المحرك ضمن النطاق المحدد`

وتعرض:

- عدد المقترحات.
- بطاقة لكل مقترح.
- حالة الجاهزية.
- سبب مختصر للتوليد.
- تفاصيل الأدلة عند الطلب.
- زر إضافة كمسودة هدف.

## مراجعة أمنية وسلامة مهنية

- لا يوجد اعتماد آلي.
- لا توجد درجة رقمية سيكومترية.
- لا ينتج المحرك ادعاء أداء جديداً.
- المقترحات غير الجاهزة بسبب غياب الدليل لا يمكن إضافتها كمسودة من بطاقة المقترح.
- مسار رفع الخطة يظل مشروطاً بموانع الجودة الحالية.

## demo على سيناريو واقعي

تعد الدورة جاهزة للتجريب عندما يستطيع المختص:

1. اختيار مجال في شاشة توليد الأهداف.
2. رؤية حتى 3 مقترحات هدف.
3. فتح سبب التوليد والأدلة.
4. إضافة مقترح جاهز أو قابل للتحسين كمسودة هدف.
5. رؤية الهدف داخل قائمة الأهداف.
6. حفظه كمسودة أو رفعه لمسار الخطة فقط عند عدم وجود موانع.
