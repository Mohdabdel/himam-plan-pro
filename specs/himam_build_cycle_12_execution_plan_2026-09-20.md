# خطة تنفيذ دورة البناء 12 - ربط معالجة المعلومات بمستوى الأداء والهدف

## قرار المنتج المرجعي

اسم الدورة: `BUILD_CYCLE_12`

النطاق الملزم: `INFORMATION_PROCESSING_TO_CURRENT_LEVEL_AND_GOAL_AUTHORING`

تغلق هذه الدورة فجوة تشغيلية بين جمع مصادر المعلومات وبين استخدامها الفعلي في إعداد مستوى الأداء الحالي وتوليد الأهداف.

## محرك مسودة مستوى الأداء

- بناء طبقة موحدة تنتج صفوف مستوى الأداء من:
  - سجلات التقييم الرسمي.
  - الملفات المرفوعة والمراجعة.
  - أدوات صوت الأسرة وصوت المتعلم وبقية أدوات المعلومات داخل المنصة.
- تصنف المسودة إلى نقاط قوة ونقاط احتياج وفق مجالات أداة التقييم الرسمية.
- لا تتحول المسودة إلى قرار نهائي إلا بعد تعديل أو اعتماد المختص.

## شاشة إعداد الخطة

- تستخدم شاشة مستوى الأداء الحالي المسودة المعالجة الجديدة عند عدم وجود حفظ سابق من المختص.
- يظهر مصدر الاقتراح مختصراً داخل كل صف.
- تبقى التفاصيل الموسعة خلف خيار استدعاء الملف التفصيلي.

## شاشة توليد الأهداف

- بعد اختيار مجال الهدف تظهر بطاقة مستوى الأداء الحالي للمجال المختار.
- تعرض البطاقة نقاط القوة والاحتياج ومصدر المعالجة المختصر.
- تساعد البطاقة المختص على اختيار الخط القاعدي وصياغة الهدف دون اعتبارها بديلاً عن قراره المهني.

## بوابة الجاهزية

تعد الدورة جاهزة إذا تحقق الآتي:

- تشغيل `npm run verify:build-cycle-12`.
- تشغيل `npm run typecheck`.
- تشغيل `npm run lint`.
- تشغيل `npm run build`.
