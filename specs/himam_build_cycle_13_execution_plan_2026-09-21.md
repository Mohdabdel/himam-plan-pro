# خطة تنفيذ دورة البناء 13 - مراجعة إنشاء مستوى الأداء والمجالات الحرة

## قرار المنتج المرجعي

اسم الدورة: `BUILD_CYCLE_13`

النطاق الملزم: `CURRENT_LEVEL_CREATION_REVIEW_AND_FREE_DOMAINS`

تعالج هذه الدورة قابلية مراجعة مستوى الأداء الحالي وقاعدة المجالات، بحيث لا تكون المجالات قائمة مغلقة إذا لم تطابق أداة التقييم المستخدمة أو قرار المختص.

## شاشة مستوى الأداء الحالي

- تعرض آلية إنشاء المسودة عند الطلب، لا الأرقام فقط.
- تبدأ المجالات من مجالات أداة التقييم الرسمية المحفوظة عند توفرها.
- يمكن للمختص تعديل اسم المجال مباشرة.
- يمكن للمختص إضافة مجال حر وبناء نقاط القوة والاحتياج ذاتياً.
- تبقى المسودة قابلة للتعديل أو الاستبعاد ولا تعتمد تلقائياً.

## شاشة توليد الأهداف

- تقرأ مجالات مستوى الأداء الحالي، بما فيها المجالات الحرة التي كتبها المختص.
- تعرض مجالات الأداة/المعالجة كاقتراحات لا كقيد مغلق.
- تظل بنود TTAP تظهر فقط عندما يكون المجال المختار من مجالات TTAP الرسمية.

## بوابة الجاهزية

تعد الدورة جاهزة إذا تحقق الآتي:

- تشغيل `npm run verify:build-cycle-13`.
- تشغيل `npm run typecheck`.
- تشغيل `npm run lint`.
- تشغيل `npm run build`.
