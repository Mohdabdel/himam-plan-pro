# خطة تنفيذ دورة البناء 17 - ربط مرجعية الخط القاعدي بمصادر المسار السابق

## قرار المنتج المرجعي

اسم الدورة: `BUILD_CYCLE_17`

النطاق الملزم: `GOAL_BASELINE_FROM_UPSTREAM_SOURCES`

تعالج هذه الدورة فجوة في شاشة توليد الأهداف: مرجعية الخط القاعدي يجب أن تبدأ من نتائج التقييم الرسمي المحفوظة ومسودة مستوى الأداء الحالي الناتجة من معالجة مصادر المعلومات، ولا تكتفي بقائمة بنود ثابتة منفصلة عن المسار السابق.

## قاعدة التشغيل

- باعث الهدف يفسر لماذا ظهر الهدف كأولوية.
- مرجعية الخط القاعدي تثبت مستوى الأداء الحالي.
- عند اختيار مرجعية تقييم رسمي، تعرض الشاشة:
  - نتائج/مجالات التقييم الرسمي المحفوظة للمجال المختار.
  - مسودة مستوى الأداء الحالي للمجال المختار.
  - بنود TTAP المرجعية كاحتياط داعم فقط عند انطباق المجال.
- يمكن للمختص كتابة تفسير خط قاعدي مراجع عندما لا توجد بنود قابلة للاختيار.

## حدود الدورة

- لا تتحول أصوات الأسرة أو المتعلم إلى خط قاعدي وحدها.
- لا تعتمد المنصة بنداً أو نتيجة دون مراجعة المختص.
- لا تضيف هذه الدورة تصحيحاً سيكومترياً أو إعادة إنتاج بنود أداة مقننة.

## بوابة الجاهزية

تعد الدورة جاهزة إذا تحقق الآتي:

- تشغيل `npm run verify:build-cycle-17`.
- تشغيل `npm run typecheck`.
- تشغيل `npm run lint`.
- تشغيل `npm run build`.
