# Himam Domain Glossary and Knowledge Model

تاريخ الإصدار: 2026-08-23  
الحالة: قاموس مجال أولي حاكم قبل schema الجديدة

## 1. قاعدة الفصل المعرفي

لا يسمح بدمج هذه الطبقات في نص واحد غير قابل للتفكيك:

| الطبقة | مثال | هل هي حقيقة رسمية؟ |
|---|---|---|
| Source | تقرير تقييم، نموذج أسرة، ملف مرفوع | بحسب المصدر |
| Extraction | قيمة مستخرجة من ملف مع مرجع | لا، حتى تراجع |
| Summary | ملخص أداء أو ملخص مصدر | لا |
| Interpretation | تحسن متسق أو احتياج محتمل | يحتاج مراجعة |
| Recommendation | جرب تعميماً أو استكمل مصدر | غير ملزمة |
| Decision | اعتماد هدف أو خطة | نعم بعد اعتماد مخول |
| AuditRecord | من فعل ماذا ومتى ولماذا | سجل تاريخي |

## 2. بطاقات مصطلحات أساسية

### Learner / المتعلم

- التعريف: الشخص الذي تبنى حوله مصادر المعلومات والخطة.
- ليس هو: الحالة الورقية أو الخطة أو التشخيص.
- علاقاته: LearnerProfile, sources, goals, plan, reports.
- ما لا يجوز استنتاجه: لا يحدد التشخيص وحده احتياجاً أو هدفاً.

### Source / المصدر

- التعريف: أصل معلوماتي له منشئ وتاريخ وسياق وغرض.
- ليس هو: دليل أداء تلقائي.
- الأنواع: تقييم رسمي، ملاحظة مهنية، صوت أسرة، صوت متعلم، تقرير سابق، ملف وسائط، عينة عمل.
- علاقاته: ينتج UploadedSourceFile أو ToolAdministration أو StructuredResponse.

### UploadedSourceFile / ملف مصدر مرفوع

- التعريف: ملف رفعه المختص أو جهة مخولة يمثل نتيجة أداة أو نموذج أو تقرير.
- ليس هو: EvidenceRecord ولا مستوى أداء.
- سياقه: اسم الملف، النوع، المصدر، تاريخ التطبيق، من رفعه، الغرض، الموافقة.
- علاقاته: ينتج ExtractedSourceDraft بعد القراءة.
- ما لا يجوز استنتاجه: لا يعتمد محتواه دون مراجعة بشرية.

### ExtractedSourceDraft / مسودة استخراج

- التعريف: معلومات قرأها النظام أو AI من ملف مرفوع مع مواضعها ومصدرها.
- ليس هو: حقيقة رسمية ولا دليل أداء.
- من يراجعها: المختص.
- علاقاته: تتحول بعد المراجعة إلى StructuredResponse أو ترفض.

### EvidenceRecord / سجل دليل أداء

- التعريف: سجل أداء مقبول مهنياً قابل للاستخدام في بناء مستوى أداء أو خط أساس.
- ليس هو: رأي أسرة، تفضيل متعلم، أو ملخص AI غير مراجع.
- الحد الأدنى: مصدر، سياق، تاريخ، مفهوم/مكون، أداء ملحوظ، مستوى دعم، SourceRef.
- ما لا يجوز استنتاجه: لا ينتج قراراً ولا اعتماداً وحده.

### KnowledgeSupportItem / معلومة داعمة

- التعريف: معلومة سياقية أو أولوية أو تفضيل تدعم التخطيط والصياغة والتقرير.
- ليس هو: دليل مستوى أداء.
- أمثلة: صوت الأسرة، صوت المتعلم، اهتمام، رؤية مستقبلية، دعم مفضل.
- قاعدة: `eligibleForLevelEngine = false`.

### InferenceSuggestion / استنتاج مقترح

- التعريف: اقتراح ربط أو تصنيف أو تفسير لم يعتمد بعد.
- ليس هو: حقيقة مؤكدة.
- أثره: صفر أثر حاكم حتى تأكيد أو رفض بشري.

### Current Performance / مستوى الأداء الحالي

- التعريف: تفسير مهني يستند إلى EvidenceRecord كاف وسياق واضح.
- ليس هو: درجة أداة واحدة أو نص مولد.
- علاقاته: يدعم الحاجة والهدف والخطة والتقرير.

### Need / الحاجة

- التعريف: فجوة أو احتياج تعليمي/وظيفي مقبول مهنياً.
- ليس هو: رغبة وحدها أو نتيجة اختبار بلا تفسير.
- يحتاج: أداء حالي، أثر، سياق، مصدر.

### Priority / الأولوية

- التعريف: ترتيب مهني/أسري/تعليمي لما يبدأ به العمل.
- ليس هو: حاجة مثبتة تلقائياً.
- مصادرها: أدلة أداء + أثر وظيفي + صوت الأسرة والمتعلم.

### Goal / الهدف

- التعريف: وحدة عمل قابلة للقياس تربط خط أساس وحاجة وسلوك ومعيار وقياس وسياق.
- ليس هو: أمنية أو مجال عام أو بند اختبار منسوخ.
- يعتمد للإدراج عبر GoalApprovalRecord.

### Plan / الخطة

- التعريف: تجميع أهداف وخدمات وأنشطة وسياقات قياس وتنفيذ لفترة محددة.
- ليست هي: قائمة أهداف منفصلة فقط.
- تعتمد كوحدة عبر PlanApprovalRecord من مختص أعلى/جهة مخولة.

### ExecutionWitness / شاهد تنفيذ

- التعريف: سجل أداء أو ممارسة أثناء تنفيذ هدف.
- ليس هو: إعادة معايرة صامتة للمستوى.
- يمكن أن يصبح دليل أداء فقط عبر مسار تحويل ومراجعة.

### Decision / القرار

- التعريف: فعل مخول يغير حالة رسمية مثل اعتماد هدف أو خطة أو تقرير.
- ليس هو: توصية AI أو فحص جودة.
- يجب أن يسجل في AuditRecord.

## 3. سيناريوهات اختبار المجال

| السيناريو | يجب أن يمثله النموذج |
|---|---|
| تقرير تقييم رسمي وملاحظة أسرة متعارضة | Conflict + Evidence/KSI separation |
| هدف جيد لغوياً بلا خط أساس | Hard stop في GoalQualityCheck |
| هدف أتقن في غرفة ولم يعمم | لا تعرض Generalized إلا بسياق تعميم |
| جلسة أداء منخفض بسبب بيئة مختلفة | Contextual witness لا فشل مطلق |
| أسرة تريد أولوية تختلف عن الفريق | Priority conflict لا حذف لصوت الأسرة |
| دليل متأخر بعد اجتماع | Audit + versioning + review |
| مدير حالة يحتاج تقريراً دون تعديل تقييم | Permission by role+relationship+purpose |
| فيديو سحبت موافقته | Consent withdrawal + retention policy |
| قرار بعد ستة أشهر | trace إلى مصدر وقرار ومراجع |
