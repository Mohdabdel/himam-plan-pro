# خطة تنفيذ دورة البناء 16 - بيانات تجريبية لمسار سابق مكتمل

## قرار المنتج المرجعي

اسم الدورة: `BUILD_CYCLE_16`

النطاق الملزم: `COMPLETE_UPSTREAM_TRIAL_PATH`

تعالج هذه الدورة فجوة أن رابط التجريب قد يصل إلى شاشة إعداد الأهداف دون وجود مسار سابق مكتمل من مصادر جمع المعلومات، مما يضعف اختبار مرجعية الخط القاعدي وباعث الهدف.

## قاعدة التجريب

- لا تختبر شاشة الأهداف منفصلة عن مصادر المعلومات السابقة.
- يجب أن تتضمن بيانات العينة:
  - سجل تقييم رسمي محفوظ في `assessment_records`.
  - ملف نتائج تقييم رسمي مرفوع ومراجع كمصدر منظم.
  - تطبيق أدوات داخل المنصة لصوت الأسرة وصوت المتعلم.
  - مصدر إضافي أو أداة غير رسمية داعمة.
  - مسودة مستوى أداء حالي محفوظة ضمن إعداد الخطة.
  - خدمات دعم محفوظة بالشكل الجدولي الجديد.

## حدود الدورة

- لا تعتمد هذه البيانات كبيانات إنتاجية.
- لا تضيف نتائج معيارية أو تصحيحاً سيكومترياً.
- لا تغيّر منطق تشغيل الشاشة؛ تضبط فقط جاهزية التجريب الداخلي.

## بوابة الجاهزية

تعد الدورة جاهزة إذا تحقق الآتي:

- تشغيل `npm run verify:build-cycle-16`.
- تشغيل `npm run typecheck`.
- تشغيل `npm run lint`.
- تشغيل `npm run build`.
