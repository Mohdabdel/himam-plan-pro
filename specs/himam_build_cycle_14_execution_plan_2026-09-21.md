# خطة تنفيذ دورة البناء 14 - تخفيف شاشة توليد الأهداف وخدمات الدعم الحرة

## قرار المنتج المرجعي

اسم الدورة: `BUILD_CYCLE_14`

النطاق الملزم: `GOAL_SCREEN_COGNITIVE_LOAD_AND_FREE_SUPPORT_SERVICES`

تعالج هذه الدورة الحمل المعرفي في شاشة توليد الأهداف، وتحول خدمات الدعم المقررة من قائمة مغلقة إلى إدخال مهني حر.

## شاشة توليد الأهداف

- إخفاء شرح عنوان اختيار آلية إعداد الأهداف خلف علامة معلومات.
- إخفاء شرح خيار منشئ الهدف التفاعلي خلف علامة معلومات.
- إخفاء شرح خيار الإدخال المباشر خلف علامة معلومات.
- الحفاظ على الشرح متاحاً عند الحاجة دون عرضه دائماً داخل الشاشة.
- مطابقة خط الشاشة وخلفيتها مع شاشة إعداد الخطة السابقة.

## خدمات الدعم

- تحويل خدمات الدعم المقررة إلى حقل حر متعدد الأسطر.
- يحفظ كل سطر كخدمة مستقلة.
- لا تفرض المنصة قائمة خدمات دعم مغلقة على المختص.

## بوابة الجاهزية

تعد الدورة جاهزة إذا تحقق الآتي:

- تشغيل `npm run verify:build-cycle-14`.
- تشغيل `npm run typecheck`.
- تشغيل `npm run lint`.
- تشغيل `npm run build`.
